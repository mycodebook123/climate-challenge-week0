# African Climate Trend Analysis
This repository contains an exploratory analysis of historical climate data for Ethiopia, Kenya, Sudan, Tanzania, and Nigeria (2015–2026) to support Ethiopia's position for COP32.

## How to Reproduce the Environment
1. **Clone the repository:**
   `git clone https://github.com/mycodebook123/climate-challenge-week0.git`
2. **Set up a Virtual Environment:**
   `python -m venv venv`
3. **Activate the environment:**
   - Windows: `.\venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`
4. **Install Dependencies:**
   `pip install -r requirements.txt`
